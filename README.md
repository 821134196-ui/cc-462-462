# 青铜博物馆 · 语音导览器借还与充电周转系统

面向博物馆柜台的导览器（设备编号 / 语言包 / 耳机 / 挂绳 / 电量 / 租借订单 / 押金 /
归还检查 / 消毒批次 / 充电槽 / 维修记录）全流程周转台。**纯 Python 标准库 + 原生前端，零依赖、零构建。**

## 一条命令启动

```bash
./run.sh                 # 自动预置演示数据并启动（默认端口 8765）
# 或：python3 -m app --reseed
```

打开 <http://127.0.0.1:8765>。参观者、金额、回执均为演示数据。
`./run.sh --keep-data` 保留现有数据；`./run.sh 9000` 换端口。

运行测试：

```bash
python3 -m unittest discover -s tests -v   # 25 项
```

## 七个工作视图

| 视图 | 角色 | 说明 |
| --- | --- | --- |
| 借用柜台 | 讲解员/主管 | 大字号、两步完成；扫码即校验语言包版本、电量、配件，确认后设备锁定「在借」 |
| 设备可用表 | 全部 | 设备柜按**编号槽位阵列**展示，电量只用**细条+数值**，语言包用短标签（中/EN/日/FR + 版本） |
| 归还检查 | 讲解员/主管 | 设备**外观照片在左、配件勾选在右**；实时计算扣款，提交后分流 待消毒/维修 |
| 消毒组批 | 消毒充电员/主管 | 待消毒设备勾选组批；**未灭菌不得放行**；放行按电量/跨馆分流 |
| 充电槽视图 | 消毒充电员/主管 | 充电柜编号槽位阵列，可标记故障槽、接入待充设备；达阈值自动入柜 |
| 维修队列 | 维修员/主管（讲解员可报修） | 语言包重灌、配件补齐、外壳按键修复；修复后强制重新消毒 |
| 押金复核 | **仅主管**可审批 | 逾期/缺件/损伤/争议订单；批准扣赔或豁免全额退 |

顶栏可切换 **讲解员 / 消毒充电员 / 维修员 / 主管** 与 **主馆 / 东翼分馆**，即时验证权限差异。

## 核心业务规则

- **借出前校验**：语言包未损坏且版本 ≥ 离线清单要求（默认阈值 80%）、电量达标、耳机挂绳在位、设备未被锁定。
- **设备排他**：同一设备同时只能被一个 `active/overdue` 订单锁定；写事务在单连接上全局加锁，
  并发借出只有一单成功（见 `test_concurrent_checkout_single_winner`）。
- **归还分流**：外壳/按键/语言包/配件任一异常 → 维修；否则 → 待消毒。
  消毒放行时：跨馆设备 → 调拨；电量不足 → 待充电；电量达标 → 可借入柜。
- **重新入柜双条件**：消毒批次已放行 **且** 电量 ≥ 80%。
- **退款幂等**：押金 `held → refunded/partially_refunded` 只发生一次；
  重复归还、重复结算均被拦截并附原支付回执，不会二次退款。
- **角色分离**：讲解员可借出/归还/**报故障**，但**不能批准赔付**、不能结案维修、不能放行消毒
  （放行归消毒充电员/主管）；跨馆调拨接收仅主管。
- **馆区权限**：人员绑定馆区，跨馆借出/组批/入槽被拒；主管可跨馆。
  **跨馆归还**允许在任意馆受理，设备标记待调拨，消毒放行后由归属馆主管接收。
- **异常分支**：语言包损坏（维修重灌）、耳机缺失（扣款+维修）、设备没电（借出拦截/归还后充电）、
  充电槽故障（停用并弹出在充设备）、逾期未还（后台扫描每 5 秒翻状态、罚金只计一次）、
  押金争议（冻结转主管）。

## 进程内任务与模拟适配器

- 后台线程：逾期扫描（5s）、充电推进（2s，每拍 +14%，满 80% 自动转「在柜可借」）。
- `app/adapters.py`：模拟**支付网关**（预授权/退款回执，退款幂等由业务层保证）
  与**充电柜**（入槽/出槽回执），替换为真实 HTTP 调用即可对接。

## 数据与文件

- SQLite：`data/museum.db`（设备、订单、押金与四项费用、批次、槽位、维修单、审计流水）。
- 外观照片：`data/photos/<设备号>.svg`（种子自动生成的留档占位图，归还页展示）。
- 离线语言包：`data/langpacks/manifest.json` + `*.lpak` 样例，版本要求以清单为准。
