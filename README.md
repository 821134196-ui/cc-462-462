# 博物馆语音导览器借还与充电周转系统

纯 Python 标准库实现(零第三方依赖):SQLite 记录设备状态,本地目录保存外观照片与
离线语言包样例,进程内任务处理逾期与充电完成,模拟适配器提供充电柜与付款回执。

## 一条命令运行

```bash
python3 app.py            # 首次自动建库+写入预置借还数据,然后服务 http://127.0.0.1:8000
python3 app.py --reseed   # 重置演示数据
python3 app.py --port 9000
```

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖:设备排他(含部分唯一索引兜底)、消毒阻断、语言包版本校验、退款幂等、
馆区权限、讲解员权限边界、逾期任务与逾期费、充电槽故障、押金争议复核。

## 页面

| 路径 | 说明 |
|---|---|
| `/counter` | 借用柜台(游客向:大字号、两步完成) |
| `/devices` | 设备可用表(状态/电量细条/语言包短标签/配件) |
| `/return` | 归还检查(设备照片旁勾选配件,定损与押金结算) |
| `/disinfection` | 消毒组批与放行 |
| `/charging` | 充电槽视图(编号槽位阵列,可模拟故障) |
| `/repair` | 维修队列(讲解员可报故障) |
| `/deposits` | 押金复核(仅复核员/管理员可批准赔付) |
| `/events` | 事件日志 |

页头可切换工作人员身份(王柜员/李柜员/赵讲解员/钱维修/孙复核/周管理员),
用于演示角色与馆区权限:跨馆借还仅跨馆授权员工可办,讲解员能报故障但不能批准赔付。

## 业务流程

- **借出**:校验语言包版本、电量(≥40%)、配件齐全 → 锁定设备(条件 UPDATE +
  部分唯一索引,同一设备不能被两个订单锁定)→ 冻结押金 ¥200 并出回执。
- **归还**:检查外壳/按键/配件 → 定损(耳机 30/挂绳 10/外壳 50/按键 40,逾期
  5 元/小时封顶 50)→ 游客认可则现场结算,有异议转押金复核;重复归还不重复退款。
- **流转**:归还后进入待消毒 → 批次放行 → 电量 <80% 入槽充电 → 达标且已消毒
  才重新入柜可借;外壳/按键损坏直接进维修队列,修复后重新走消毒。
- **特殊流程**:语言包损坏/版本不符借出拦截;设备没电自动充电;充电槽故障暂停
  充电待修;跨馆归还需授权;押金争议进复核队列;逾期由后台任务标记并计费。
